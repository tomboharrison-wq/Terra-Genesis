# Decisions (append-only)

- 2026-10-22 — Stack pinned to known-stable versions (three 0.170, React 19.1, Vite 6.3, Vitest 3.2, TS 5.8, zustand 5) rather than newest majors; reason: API certainty. Trade-off: upgrade later deliberately.
- 2026-10-22 — Renderer ownership: one imperative `TerrainScene` class owns all Three objects; React only mounts a container and calls methods. Reason: avoid dual scene ownership (spec C1).
- 2026-10-22 — Terrain mesh: one BufferGeometry, vertex per cell centre; dirty-region updates recompute normals/colours on CPU for the dirty rect and upload a contiguous row range via `addUpdateRange`. Reason: no chunk seams at ≤512². Trade-off: 1024² may need true chunking (revisit at M01-C07/M09).
- 2026-10-22 — Picking via heightfield ray-march (`terrain/heightfield.ts`), not Mesh.raycast. Reason: O(steps) not O(triangles); testable without WebGL.
- 2026-10-22 — Brush edit rule: positive dz adds bedrock; negative dz removes loose sediment first, then bedrock; sediment brushes edit sediment only. `materialId` = bedrock lithology. Surface colour blends lithology with loose-sediment colour by thickness.
- 2026-10-22 — Generation runs on main thread (≤512² is tens of ms). Workers reserved for M02+ solvers.
- 2026-10-22 — Static sea-level plane rendered at `seaLevelM` as a representation of the sea-level parameter only; it is NOT hydrology (M02) or a coastal model (M05).
- 2026-10-22 — Save format `.tgw`: magic+JSON header+raw little-endian typed arrays, gzip via CompressionStream. IndexedDB stores the same bytes.
- 2026-10-22 — World rendered as a diorama block (earth skirts + sea confined to map) rather than infinite ocean; reads correctly for inland presets.
- 2026-10-22 — `window.__terraGenesis` exposes read-only engine/checksum/bench hooks for e2e browser checks.
- 2026-10-22 — Water routing = local-inertial (Bates 2010) in non-negative 4-pipe form; flux grows with face flow depth (the plain cs² pipe model was unstable: depth-independent wave speed). Sea cells = fixed-head sink. Inland cells below sea level are also treated as sea (limitation).
- 2026-10-22 — CPU solver too slow for interactive use (~20 ms/step at 256²); GPU port planned as M02-C03, CPU kept as reference.
- 2026-10-22 — GPU water = raw WebGL2 passes on three's context (forcing / flux / update, RGBA32F ping-pong, MRT accumulators); three binds the state texture via renderer.properties injection; renderer.resetState() after compute. CPU arrays are a mirror synced every 0.25 s and before save.
- 2026-10-22 — Generated terrain is drainage-conditioned by priority-flood with a 0.2% gradient; fill volume is added as loose sediment (alluvium), bedrock untouched.
- 2026-10-22 — Sediment = single-class suspended load (bulk m) advected with the water solver's own face discharges (upwind, exactly conservative); capacity C = K·q·S; loose sediment eroded before bedrock (× lithology erodibility × bedrockFactor); bedrock change booked as the exact float32 delta. Sea cells receive settling sediment (sea-floor building).
- 2026-10-22 — GPU: water passes read surface from a shared bed texture (bedrock, loose, suspended, erodibility); a 4th pass does creep → advection → exchange; rain measured on GPU (acc.g), infiltration+evaporation share acc.r split by rate ratio on sync. Long advances sync every 600 s.
- 2026-10-22 — Change map neutral band ±5 cm; hillslope creep default off (measured: it mostly smooths generator micro-relief at ×300).
- 2026-10-22 — Stratigraphy by absolute elevation per cell (3 boundaries / 4 layers), not by thickness: erosion can never make a layer negative and exposure is a pure lookup (CPU + GPU). materialId kept as derived exposed lithology for compatibility.
- 2026-10-22 — Weathering demand accumulates in a pending store (CPU array / GPU bed.a) because per-step production is below float32 resolution at high elevations.
- 2026-10-22 — Slope stability uses a saturation proxy (surface water depth or rain intensity) until a soil-moisture field exists (M06).
- 2026-10-22 — Rotational slumping is a separate guided 2D model (Fellenius method of slices + rigid rotation about the critical circle + equal-area toe lobe), labelled as such and not coupled to the heightfield; the map uses generalised mass movement.
- 2026-10-22 — Coastal processes run on the CPU at a fixed 600 s simulated cadence (Engine.coastHook: GPU sync → update → re-upload); wave power from deep-water energy flux with shelter/incidence/attenuation multipliers; drift CERC-like with Jacobi transfers. Shares the geomorphic acceleration with erosion.
- 2026-10-22 — New worlds are settled to the simulator's dry stability limits at generation (rockfall + talus), so change maps show only real process change.
- 2026-10-22 — Lava (M08) is a CPU Bingham flow that sub-steps inside each water step (own 2–5 s step, ⅛ level-difference cap instead of tiny steps near thick vents). Lava is not part of the derived surface for water until it solidifies (60 s cadence) into a volcanic top layer via addTopRock; buried soil becomes a weak sedimentary layer.
- 2026-10-22 — Tephra (M08-C02) is laid instantly every 600 s of simulated time (and when a vent stops) as loose sediment with a display-only tephraM share; vent rate is magma (dense rock) rate, tephra bulk = 2.6×.
- 2026-10-23 — Volcano builds (M08-C03) run each eruption with the real lava/tephra physics but skip the rest years between eruptions (freezeAll: remaining lava → rock; water/erosion do not run) — labelled time compression in the UI. Lava step floor raised to 2 s (the ⅛-difference cap keeps it monotone).
- 2026-10-23 — Volcanic island preset grows its island at generation with the same eruption code as volcano builds (Surtseyan plan: explosive with 85 % near-vent tephra while the vent is under water, then 3 lava eruptions). Calderas are a rigid piston on a ring fault (no chamber model); the dropped block keeps its shape.
- 2026-10-23 — Map overlays are data-driven defs (renderer/overlays.ts) shared by renderer, legend and inspector; offered only when their field has data. Flow accumulation is plain D8 on the current surface (stops in hollows/at sea; parallel lines on filled flats are the known D8 artefact). Aspect treats < 0.5° as flat.
- 2026-10-23 — Education Mode: emergent lessons run the real engine and keep a private per-stage world copy (Previous restores it, never runs backwards); labels come from D8 features of the current surface. Guided lessons render deterministic local models (waterfall, meander) instead of the map, always badged 'Guided model'.
- 2026-10-25 — Floods (M11-C01): flood extent = per-cell peak water depth updated after every solver step (CPU loop; GPU max pass into its own ping-pong texture, folded on sync), counted where it rose ≥ 0.3 m above the depth at the event start. Sea surge = the sea's fixed head raised by a smooth timed profile; sea cells become unlimited sources facing land neighbours (same local-inertial face rule), ledgered as surgeIn (GPU: the sea cell's unused infiltration slot). Not a travelling wave; all sea cells (incl. inland below-sea cells) rise together — stated in the UI.
- 2026-10-25 — `.prettierrc` added (single quotes, width 160 — the style of the committed engine code); styles.css and some app files had never been formatted and were normalised once.
- 2026-10-25 — Meteor craters (M11-C02): Collins et al. 2005 pi-scaling for the transient crater, Pike d = 0.196 D for simple craters; bowl cut to d/1.25 below a reference plane (mean pre-impact height), ejecta (R/r)³ normalised to the excavated volume over an infinite plane so the off-map share is explicit; no bulking, melt, central peak or airburst (stated in the panel). Droughts reuse the event depth record in 'low' mode (GPU pass uLow). The event log survives checkpoint restores of the same world (createdAtIso) so runs can be compared.
- 2026-10-26 — @types/node added (dev) for vite.config.ts (commit id for the version string; Netlify's COMMIT_REF preferred). Build identity __APP_VERSION__ shown in Help and on window.__terraGenesis.version.
- 2026-10-26 — Landform Show is a separate full-screen teaching player (not the map simulation): formations are data (src/education/landforms/content.ts: stages, KS3/GCSE text, active processes, timescales, glossary, exam steps — all tested for spec coverage and consistency) drawn by SVG scene functions of (t, time). Where a tested guided model exists it drives the drawing; otherwise the drawing is an animated textbook sequence, badged as such. Timescales are approximate and stated with a note. Simulator time-lapse = max speed + the existing ×1000 accelerations (not a new physics shortcut).
- 2026-10-26 — Adaptive per-frame step cap in SimClock (≤ 64; ×0.6 when a real frame takes > 0.1 s, +2 when < 0.05 s). Reason: GPU steps are queued cheaply, so the 10 ms CPU budget let fast speeds queue far more GPU work than a slow chip could run — measured in headless SwiftShader: 27–58 s frames in time-lapse, ~1 s after the cap (same as idle there). Physics unchanged (fixed-step; frame-rate test still bit-identical).
- 2026-10-27 — Mac app = Electron wrapper (desktop/, own package.json so the web build gets no Electron dependency) around the unchanged dist/. Served from a privileged `app://terra/` scheme (standard + secure) rather than file:// so module scripts, fetch, IndexedDB and WebGL2 behave as on the website; path-traversal-checked. Ad-hoc signed only (no Apple Developer ID / notarisation), so macOS asks once on first open — documented in HOW-TO-INSTALL.txt. Built on Linux with @electron/packager + rcodesign; on a Mac the script uses codesign.
- 2026-10-29 — Geological time is a second, long-timescale model (sim/geology/landscapeEvolution.ts), not more acceleration of the hydraulic solver: measured water steps are ~1.25 s on 30 m cells once valleys hold ~5 m of water, so even 64 steps/frame gives ≤ ~4,800 s/s — ~0.15 landscape-years per real second at ×1000. Model: priority-flood drainage (lakes fill and spill), detachment-limited stream power n = 1, m = 0.5, solved implicitly (Braun & Willett 2013), K = 1e-5 m⁰/yr × rock erodibility (×2 on soil ≥ 0.5 m); soil production 1e-4 m/yr × erodibility × e^(−h/0.5); linear creep D = 0.01 m²/yr flux-limited to soil; threshold hillslope failure at 30° (mudstone) … 52° (granite) = clamp(30 + 25(1 − e), 25, 55)°, capped by the rock's cliff angle, land only and only down to sea level; sediment deposited in hollows up to the spill level and in the sea to 1 m below sea level, the rest offshore; sea at a map edge exports (the sea continues beyond the map). Step length ≤ 5,000 yr and ≤ 2 cells of knickpoint travel (c = K·A^m) — measured: 5,000-yr steps smeared a 60 m waterfall away, ≤ 1,000-yr steps kept it. No floodplain aggradation, glaciers, waves, lava or plants in geological time (stated in the UI). Runs in a Web Worker on copies of bed/soil/strata; a result computed from terrain a tool changed meanwhile is discarded.
- 2026-10-29 — Geological rivers/lakes are drawn from drainage area (channel where ≥ 5×10⁴ m² drains, typical channel-head areas 0.01–0.1 km²) and lake level, not put into the water solver (that would be water the hydraulic model did not compute). Pressing water-time Play removes them; real rain makes real rivers again.
- 2026-10-29 — Record & replay keeps ≤ 48 frames (bed, soil, material: ~0.6 MB each at 256²), about one per real second of running; past 48, every other frame is dropped so the whole span stays. Replaying restores the world exactly; running from an earlier frame discards later frames.
- 2026-10-29 — Geological lessons use purpose-built deterministic worlds (education/scenarioWorlds.ts): a plateau with sandstone / 28 m dolerite / shale (Teesdale analogue) and an upland of sandstone over mudstone with winding initial valleys. Labels are measurements (geoFeatures.ts: main river, largest drop within 300 m that includes hard rock, cross-valley depth / half-height side slope / floor width, spurs = high ground inside river bends). Stages run in the worker in ~10 chunks so the change is seen.
- 2026-10-29 — Codex's 1 mm water display threshold reverted after a same-world same-rain comparison: millimetre sheet flow tinted every slope.
